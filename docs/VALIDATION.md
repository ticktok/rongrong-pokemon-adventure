## 可重复验证

本地纯代码检查使用 npm run typecheck、npm test、npm run build。

连接真实测试家庭的脚本位于 scripts：

- e2e-live.mjs：完整交互流程；先初始化独立 QA 存档。
- verify-adventure.mjs：后期道馆、分支赠礼、进化与捕捉。
- verify-database.mjs：权限、并发及幂等。
- verify-admin.mjs：部署网址上的家长编辑与断网重试。
- verify-quiz-recovery.mjs：答题中的断网与恢复。
- production-smoke.mjs：正式家庭的登录、读取与导出，不选择伙伴。

这些脚本依赖被忽略的 private 配置，不在公开 CI 中访问家庭数据；多个真实环境脚本不要并行操作同一个 QA 存档。运行报告和截图保存在本机 artifacts 目录。
